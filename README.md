# Muhammad Dawood Portfolio

This is my personal portfolio website. It is a simple one page site that shows
who I am, what work I have done till now.


## What is on the Website

The website has these parts:

- **Home**: A short intro about me,that shows what I do.
- **Work Experience**: A timeline of my work and experiences so far.
- **Contact**: My email and phone number, so people can reachout to me.

## Built With

- HTML
- CSS
- JavaScript (Typed.js for the typing effect)
- Poppins font from Google Fonts
