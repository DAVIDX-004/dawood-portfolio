# Muhammad Dawood Portfolio

This is my personal portfolio website. It is a simple one page site that shows
who I am, what work I have done, and how people can contact me.

## About the Project

I made this portfolio to present myself online. It has a dark blue theme with
purple highlights. The site is clean and easy to read.

## What is on the Website

The website has these parts:

- **Home**: A short intro about me, with a typing effect that shows what I do.
- **Work Experience**: A timeline of my work and experience so far.
  - Web and Wordpress Developer at Paptech College (2024 - 2026)
  - Digital Marketer and SEO Expert at BanoQabil (2025 - 2026)
  - Social Volunteer at Alkhidmat Foundation (June 2026 - Present)
  - Founder of David Courses Hub (2024 - Present)
- **Contact**: My email and phone number, so people can reach me.

## Built With

- HTML
- CSS
- JavaScript (Typed.js for the typing effect)
- Poppins font from Google Fonts

## How to Use

1. Download or clone this repository.
2. Open the `index.html` file in your web browser.
3. That is it. No installation needed.
